# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately, either by e-mail to the security contact published at `/.well-known/security.txt` on the live site, or through GitHub's **Report a vulnerability** (private advisory) in this repository. Do not open a public issue.

Include the affected URL or component, the steps to reproduce, and the impact you observed. We aim to acknowledge reports within 7 days. This is a volunteer-run band website, so we cannot offer a bug bounty.

## Scope

In scope: this repository's code and the deployed site. Out of scope: denial-of-service volume testing, social engineering of band members, and third-party services (hosting provider, e-mail provider).

Do not access, modify or download other people's data, beyond the minimum needed to demonstrate an issue.

## Supported versions

Only the current `main` branch is deployed and supported.

The technical security design is described in [docs/security.md](docs/security.md).
